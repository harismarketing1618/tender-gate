# TENDER GATE 🏢🇵🇰

> **Pakistan's Premier Autonomous Construction Procurement & Tender Intelligence Platform**

TENDER GATE indexes, structures, and audits public sector tenders across 24+ federal and provincial government e-procurement portals in Pakistan (Federal PPRA, Punjab PPRA, Sindh SPPRA, KPK KPPRA, NHA, WAPDA, IDAP, MES, and CDA).

---

## 🌟 Key Features

- 🤖 **8 Autonomous AI Agent Crawlers:** Specialized bot grid crawling and classifying daily tenders across infrastructure, high-rises, MEP, dams, defense, municipal works, and consultancy.
- 📐 **PEC Category Eligibility Matcher:** Instant contractor verification against Pakistan Engineering Council (PEC) limits (C-A through C-6) and engineering specialization codes (CE-01, BC-01, EE-04, ME-01).
- 💰 **Automated Financial Calculation:** Real-time 2% Call Deposit Receipt (CDR) earnest money and performance guarantee estimation.
- ⚖️ **Side-by-Side Comparison Matrix:** Compare up to 3 competitive tenders simultaneously.
- 💬 **WhatsApp & Email Alerts:** Instant notification channels for contractor associations and engineering firms.
- 🔒 **RuFlo Zero-Trust Enterprise Security:** Threat sanitization, rate limiting, and secure audit trails.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/harismarketing1618/paktender.git

# Navigate into project directory
cd paktender

# Install dependencies
npm install
```

### Running Locally

```bash
# Start Vite development server
npm run dev

# Start Node.js / Express Backend Server
npm run server
```

### Building for Production

```bash
npm run build
```
